# Real field photos go here

Phase B8 requires 30–50 original crop photos covering clean, lightly infected, and heavily infected plants. These must be collected by a person with permission; synthetic images and downloaded dataset samples do not count as field evidence.

For each batch, record crop, approximate setting, date, device, and consent/ownership in a small adjacent Markdown or CSV manifest. Preserve difficult lighting, blur, soil, hands, and clutter so Dev A can measure the real lab-to-field gap honestly.
